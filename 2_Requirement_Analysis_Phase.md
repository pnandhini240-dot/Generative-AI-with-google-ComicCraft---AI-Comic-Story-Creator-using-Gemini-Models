2. Requirement Analysis Phase
Objective
To identify and analyze the functional and technical requirements needed to develop the ComicCraft AI Comic Story Creator using Google Gemini models.
Activities
• Identified the software and hardware requirements for the project.
• Selected Google Gemini models for AI-based story generation.
• Selected Python as the programming language for development.
• Planned GitHub for project development and version control.
• Identified user story input and AI-generated comic story features.
• Planned a simple and user-friendly interface for the application.
• Identified the requirements for generating stories, characters, dialogues, and comic scenes.
Result
The functional and technical requirements of the ComicCraft project were successfully identified and analyzed, providing a clear foundation for the project design and development
